教師影片箭頭標註｜使用方式

1. 將 ZIP 完整解壓縮，保留資料夾內容。用 Chrome 或 Edge 開啟「開啟教師標註.html」。
2. 到要標註的投影片，選擇影片序列。用進度條或「前一格／後一格」停在要標的影格。
3. 按該影片下方「畫箭頭」，在影像內從箭尾拖到箭尖。預設只在當下的影格顯示。
4. 要顯示好幾張：在「本影片的箭頭」選取該箭頭，填「起始張／結束張」，按「套用」。
   可改顏色、跳回起始張或刪除。位置不對時刪除後重畫。切換影片不會把箭頭套到別的序列。
5. 完成後按右上方「下載標註」，到瀏覽器「下載項目」確認 JSON 檔。
   只需把 JSON 回傳給教材維護者，不用重傳影片、影像或整個資料夾。
6. 想繼續編輯時，用同一版教材開啟「匯入標註」，選擇之前下載的 JSON。
   下載前的變更只在目前視窗；未完成請先下載，不要只關閉頁面。

這是離線教師版，不需要密碼、帳號、安裝程式或伺服器。箭頭是額外的標註，不會覆蓋原影片。
建議只分享給參與標註的老師。此資料夾包含教材影像；回傳的 JSON 則只包含標註資料與版本代號。
同一老師若下載多個版本，請明確告知維護者要採用哪一份。公開學生版不會自動更新。
